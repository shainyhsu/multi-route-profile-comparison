# Multi-Route Profile Comparison: changelog

- V18 | 2026-11-13 09:20 | Added a tab icon and an "All tools" link in the footer; the GPX upload has a label for screen readers.
- V17 | 2026-11-13 07:40 | The A4 share picture fills its pages: when it runs just over a page (up to about 18%), the whole layout is shrunk to fit one page fewer, and the room left on a nearly full page is spread between its parts instead of sitting blank at the bottom
- V16 | 2026-11-13 01:40 | One link per comparison: sharing again after changes asks whether to update the old link (everyone who has it opens the new version) or make a new one. The save panel and picture footer show the case code, version and time

- V14 | 2026-11-12 21:20 | Mirror: points on the way back now take the name and on/off setting of the same point on the way out (rename either one and both change), and the high point is marked on the way back at its mirrored spot
- V13 | 2026-11-12 20:25 | Mirror fixes: the old end becomes a turnaround point in the middle (named by the end name, or Turnaround), the end always shows the start name, and points you added on the one-way line now show on the way back too
- V12 | 2026-11-12 19:30 | Mirror option next to Reverse: the route comes back the same way, so the line ends where it started and named points show on the way out and back; on phones the docked profile editor now always opens expanded, and when hidden it shows a large colored "Open profile editor" button
- V11 | 2026-11-11 16:55 | Card legend now lists every route (main route first), each with a length bar under it on the same km scale as the profile, showing the pack load; the span arrows above the elevation profile are gone
- V10 | 2026-11-11 16:40 | Reverse now swaps the start and end names on every route (typed names and named points), and a route named like "A-B" or "A→B" becomes "B-A"; an end with no name is labeled Destination (目的) instead of the route name
- V9 | 2026-11-11 16:20 | Notes moved to a ? button in the header, next to Save; each route's settings now end with a Collapse button, so you don't have to scroll back up to close them
- V8 | 2026-11-11 11:45 | Pasting a save link into a tab that already has the page open now loads it too (before, only a fresh open did)
- V7 | 2026-11-11 11:25 | Save links are now short (about 90 characters): the save is encrypted in your browser, only the scrambled copy is stored online, and the key stays in the link, so whoever has the link can open it without signing in; the full link is used if the short one can't be made
